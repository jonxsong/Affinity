# Contributing to Affinity

Thank you for helping make recommendation engineering more reproducible.

1. Open an issue for broad architectural changes.
2. Create a focused branch and add tests with behavior changes.
3. Run `pnpm lint && pnpm typecheck && pnpm build` plus the relevant Rust or Python suite.
4. Include dataset versions, seeds, hardware, duration, and configuration with performance claims.
5. Keep public, synthetic, and application-originated data clearly separated.

Please do not commit credentials, downloaded datasets, generated model artifacts, or private interaction histories.
